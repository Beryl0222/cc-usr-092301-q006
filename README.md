# 群众赛事医疗资源编排

本项目用于整理群众赛事医疗资源编排领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号。

## 目录

- `src/`：事件种类、安全合同校验、规范化摘要与批量接收（去重/冲突）。
- `data/sample.json`：用于核对资料格式的虚构事件。
- `tests/`：保证样例与领域约定保持一致，并覆盖对抗性输入。

## 接收合同

- 只接受普通 JSON 对象（原型为 `Object.prototype` 或 `null`）**自身**的可枚举数据属性；原型链上的必填字段、`__proto__`/`constructor`/`prototype` 自有键一律拒绝。
- 校验全程只读取属性描述符，**永不执行 getter/`toJSON` 等外来代码**。
- 空值、数组、访问器属性、循环结构、非 JSON 值（`NaN`/函数/symbol 等）和读取时抛异常的代理都返回确定性错误码（见 `ProblemCode`），不抛异常、不回显原值。
- 批量接收（`createInbox().receive(records)`）的每条结果与原序号绑定，单条异常只隔离该条；已通过的记录按 `event_id` 与规范化 SHA-256 摘要去重。
- 同一 `event_id` 但摘要不同的重放进入 `conflicts` 队列等待人工处理，不会静默采用先到或后到版本。
- 错误响应（`toErrorResponse`）与日志只包含序号、安全标识、错误码、路径和摘要，不含记录内容。
